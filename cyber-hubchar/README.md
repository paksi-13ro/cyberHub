# 🎯 Picker SVG — инструмент подбора координат

Инструмент для быстрого подбора координат полей на изображении листа персонажа. Позволяет мышкой выделить область на картинке и получить готовый SVG-код с `<foreignObject>` и вложенным `<input>`.

## 🚀 Зачем это нужно

Когда нужно наложить интерактивные поля (input, checkbox, textarea) на статичную картинку (например, PDF-лист персонажа для Cyberpunk RED), приходится вручную считать координаты. Этот инструмент делает 
это автоматически:

1. Ты видишь картинку листа
2. Тянешь мышкой по области, где должно быть поле
3. Заполняешь название и ID
4. Получаешь готовый SVG-код, который остаётся только скопировать

## ✨ Возможности

- 🖱️ **Мышью выделяешь область** — координаты считаются автоматически
- 📐 **Точность до пикселя** — работа в системе `viewBox` SVG
- 🎨 **5 типов полей:**
  - `text` — обычный текстовый ввод
  - `number` — числовой ввод (без спиннеров)
  - `textarea` — многострочный ввод
  - `readonly` — только для чтения (для STAT и СУМ в автосчёте)
  - `checkbox` — чекбокс (для кибермилантов)
- 🔢 **Автоподстановка `data-stat`** — для полей характеристик (INT, REF, WOL и т.д.)
- 📋 **Копирование всего кода** одной кнопкой
- 💾 **Накопительный режим** — сохраняешь поля одно за другим
